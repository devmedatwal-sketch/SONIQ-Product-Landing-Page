# SONIQ – Responsive Product Landing Page

A responsive product landing page for fictional wireless headphones, built using HTML5, CSS3 and Tailwind CSS.

## Sections
- Navigation bar
- Hero section with product image and call-to-action
- Product features
- Benefits
- Customer reviews
- Pricing and call-to-action
- Footer with contact and social links

## Technologies
- HTML5
- CSS3
- Tailwind CSS (CDN)
- Flexbox and CSS Grid
- Responsive design with media queries and Tailwind breakpoints

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Internet connection is required for Tailwind CDN and the product image.

## Note
SONIQ and the product pricing are fictional and used for this educational project.
